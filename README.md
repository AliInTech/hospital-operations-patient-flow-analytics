
# Hospital Operations & Patient Flow Analytics

## Project Overview
A Power BI analytics project designed to analyze hospital
operations and patient flow and support data-driven decisions.

## Business Objectives
- Analyze patient visit trends.
- Compare performance across departments.
- Understand doctor and nurse workloads.
- Evaluate bed utilization.
- Analyze patient complaints and severity.
- Monitor service-level targets, where applicable.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- SQL Server (if used)
